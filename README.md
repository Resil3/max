# MAX Chat

Веб-чат на React для обмена текстовыми сообщениями через GREEN-API MAX. Работает локально и может быть опубликован на Vercel. Каждый запрос использует учётные данные, введённые в конкретном браузере; приложение не сохраняет токены и не использует общий серверный инстанс.

## Возможности

- Подключение инстанса по `idInstance`, `apiTokenInstance` и URL API.
- Проверка статуса инстанса.
- Отправка текстовых сообщений на номер с кодом страны.
- Получение входящих текстовых сообщений во время открытой вкладки и подтверждение уведомлений через `DeleteNotification`.
- Поиск по локальной истории сообщений.
- Адаптивный интерфейс для компьютера и телефона.

## Требования

- Node.js 18 или новее.
- Инстанс GREEN-API MAX, авторизованный по QR-коду.
- В настройках инстанса должно быть включено получение уведомлений. Для получения через HTTP API поле `webhookUrl` должно быть пустым.

## Локальный запуск в Windows

1. Установите Node.js LTS.
2. Откройте PowerShell в папке проекта.
3. Установите зависимости и запустите приложение:

   ```powershell
   npm install
   npm run dev
   ```

4. Откройте `http://localhost:5173`.
5. Нажмите **＋** или шестерёнку, введите данные инстанса из личного кабинета GREEN-API и номер собеседника, затем нажмите **«Подключить»**.

Токен находится только в памяти открытой вкладки и передаётся API по HTTPS в продакшене (локально — серверу на вашем компьютере). После обновления страницы его нужно ввести снова. Не публикуйте токен и не добавляйте его в Git.

### Локальный production-запуск

```powershell
npm run build
npm start
```

Откройте `http://localhost:3001`.

## Публикация на Vercel

1. Загрузите папку проекта в GitHub.
2. Войдите на [vercel.com](https://vercel.com), выберите **Add New → Project** и импортируйте репозиторий.
3. Оставьте обнаруженные настройки Vite: команда сборки `npm run build`, папка результата `dist`.
4. Нажмите **Deploy**. Секреты GREEN-API в настройках Vercel добавлять не нужно: каждый пользователь вводит данные собственного инстанса в чате.

Файл `vercel.json` и обработчики в `api/` уже настроены для Vercel. Для локальной разработки React-приложение обращается к тем же API через Vite proxy.

## Важные ограничения

- Получение ответов работает, пока вкладка сайта открыта. GREEN-API HTTP ReceiveNotification использует опрос; фонового синхронизатора/хранилища истории на сервере нет.
- История хранится в локальном браузере и не синхронизируется между устройствами.
- Для одного и того же инстанса несколько открытых вкладок могут конкурировать за очередь уведомлений GREEN-API.
- Публичный сайт — демонстрационный клиент. Не вводите на нём токены, если не доверяете размещённой версии сайта и её владельцу.

## Структура

- `src/` — интерфейс на React.
- `api/` — serverless-обработчики Vercel.
- `server/` — общая логика GREEN-API и локальный Express-сервер.
