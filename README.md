# MAX Chat

Веб-чат на React для отправки и получения текстовых сообщений через GREEN-API MAX. Инструкция ниже описывает локальный запуск на Windows.

## Возможности

- Подключение инстанса по `idInstance`, `apiTokenInstance` и URL API.
- Проверка статуса подключения.
- Отправка текстовых сообщений на указанный номер.
- Получение входящих текстовых сообщений во время открытой вкладки и подтверждение уведомлений через `DeleteNotification`.
- Поиск по истории сообщений, сохранённой в браузере.
- Адаптивный интерфейс для компьютера и телефона.

## Требования

- Node.js 18 или новее.
- Инстанс GREEN-API MAX, авторизованный по QR-коду.
- В настройках инстанса включено получение уведомлений. Для получения через HTTP API поле `webhookUrl` должно быть пустым.

## Локальный запуск на Windows

1. Установите Node.js LTS.
2. Откройте PowerShell в папке проекта.
3. Установите зависимости и запустите приложение:

   ```powershell
   npm install
   npm run dev
   ```

4. Откройте `http://localhost:5173`.
5. Нажмите **＋** или шестерёнку, укажите данные своего инстанса GREEN-API и номер собеседника с кодом страны, затем нажмите **«Подключить»**.

Учётные данные остаются в памяти открытой вкладки и передаются локальному серверу для вызовов GREEN-API. После обновления страницы их потребуется ввести снова. Не публикуйте токен и не добавляйте его в Git.

### Локальный запуск production-сборки

```powershell
npm run build
npm start
```

Откройте `http://localhost:3001`.

## Структура проекта

- `src/` — интерфейс на React.
- `api/` — обработчики API.
- `server/` — локальный сервер и логика работы с GREEN-API.

## Ограничения

- Входящие сообщения проверяются, пока вкладка чата открыта.
- История сообщений хранится в локальном браузере и не синхронизируется между устройствами.
- Несколько вкладок, подключённых к одному инстансу, могут конкурировать за очередь уведомлений GREEN-API.
